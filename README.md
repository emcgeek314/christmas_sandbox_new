Christmas Events Calendar - Testing Sandbox
Welcome to the sandbox repository for testing updates to the Ellen's 2026 Christmas Events Calendar web application!
This repository is isolated from the live production site. Use it to safely test new features, layout updates, and JavaScript modifications (such as the "Add to Calendar" button and date-picker modal) before pushing them to your main public repository.
Project Structure
index.html: The main web application interface and embedded logic.
christmas_events_v2.json: The master holiday event data feed.
Testing Workflow
1. Upload your updated index.html file to this sandbox repository.
2. Visit your sandbox GitHub Pages URL to verify that:
The template and background styling load correctly.
Event cards and dates populate properly from christmas_events_v2.json.
New interactive features function as expected on mobile and desktop.
3. Once a feature is fully verified and working in this sandbox, safely apply the changes to your production repository!
